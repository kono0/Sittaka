会話ログ

    Sarashina の API キー

    拾う言葉の量

    AI を使っているときの量です。キーがないときは変わりません。

    自分の声に使うマイク

    Bluetooth のイヤホンのマイクを使うと、イヤホンが通話用のモードに切り替わって音質が落ちます。 そのときは PC 内蔵のマイクを選ぶか「使わない」にしてください。相手の声の取り込みには影響しません。

    文字起こしエンジン

    止めている間だけ変えられます。

    認識のヒント（実験中）

    ReazonSpeech のときだけ効きます。次に「開始」したときから使われ、処理は少し遅くなります。 似た音の別の言葉までヒントに引っぱられることがあるので、検証タブで良くなったか確かめてください。

    データの扱い

    キーはこの PC の中に暗号化して保存します。キーを入れると、聞き取った文章と調べる言葉を Sarashina に送って、言葉の絞り込み・漢字の直し・意味の説明をさせます。 Sarashina の無料版では、送った内容が AI の学習に使われます。音声そのものは送りません。
